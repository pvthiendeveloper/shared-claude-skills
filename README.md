# shared-claude-skills

Skills for [Claude Code](https://claude.com/claude-code) that you can copy and use.

| Skill | What it does |
|---|---|
| [`stickman-video`](stickman-video/) | Turns a topic into a finished faceless stick-figure (người que) video: script, voice, character sheet, AI images, AI clips for key scenes, free motion for the rest, captions, MP4. |

## Install a skill

```bash
git clone https://github.com/pvthiendeveloper/shared-claude-skills.git
cp -r shared-claude-skills/<skill-name> ~/.claude/skills/
```

Each skill folder has its own README with requirements and usage.
